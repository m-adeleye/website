# Terminal-inspired portfolio

React + Vite + Tailwind CSS starter matching the terminal-style portfolio mockup.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Customize

- Edit `src/main.jsx` to update the project cards, introduction, and experience.
- Update the GitHub and email links in the footer.
- Create `public/resume.pdf` with your resume to enable the Resume link.
- Change colors and styling in `src/index.css` and Tailwind classes.

## Build for deployment

```bash
npm run build
```

Deploy the generated `dist` folder to Vercel, Netlify, or GitHub Pages.
